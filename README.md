# synergie-daten

Öffentliche, datensparsame Daten der SYNERGIE-Seite (automatisch erzeugt, nicht von Hand bearbeiten).

- `Blick.json` – öffentliche Fassung des Netz-Blicks (ohne Kontakte, Adressen, interne Notizen)
- `blick-widget.js` – dieselben Daten als `window.SYNERGIE_BLICK`
- `mixes.json` – Mixtapes (Audio-Dateien liegen auf der Seite unter `audio/`)
